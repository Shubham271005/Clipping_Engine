Privacy Policy

Clip Studio (Clipping Engine) · Last updated: 19 November 2026

Clip Studio is a personal, self-hosted tool used by its owner to edit short video clips and publish them to the owner's own YouTube channel and Instagram account. It is not offered to the public and has no other users.

Data accessed through Google / YouTube APIs

  • YouTube upload (youtube.upload): to upload videos, titles, descriptions and tags to the owner's channel.
  • YouTube read-only (youtube.readonly): to read the owner's channel name and the public statistics of uploaded videos.
  • YouTube Analytics read-only (yt-analytics.readonly): to read view, watch-time and engagement metrics of the owner's videos.

How data is stored and used

  • OAuth tokens and analytics are stored only on the owner's own computer, in local files and a local SQLite database.
  • Data is used only to publish the owner's clips and to show the owner how those clips perform.
  • No data is sold, shared with third parties, or used for advertising.
  • Instagram data (via the Instagram API) is handled the same way: the access token and post metrics stay on the owner's computer.

Revoking access

Access can be revoked at any time from Google Account → Third-party access. Deleting the local token file also removes the app's access.

Google API Services User Data Policy

Clip Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API usage is subject to the YouTube Terms of Service and the Google Privacy Policy.

Contact

Questions about this policy: contact the channel owner through the email listed on the OAuth consent screen.
